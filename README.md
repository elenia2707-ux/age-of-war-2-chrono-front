# 전쟁시대 2: 크로노 프론트 (Chrono Front)

아이폰 사파리(모바일 웹 + 홈 화면 PWA) 가로 모드에 최적화된 **전쟁시대 2(Age of War 2)** 스타일 7시대 진화 2D 횡스크롤 전략 디펜스 게임입니다.

## 주요 특징

- **7단계 시대 진화 (원시 → 고대 → 중세 → 화약·근세 → 세계대전 → 현대 → 미래)**
  - 총 22종 관절형 Canvas 2D 유닛(걷기·공격·피격 플래시·사망 모션)
  - 총 14종 시대별 자동 사격 포탑(슬롯 확장 1→4, 설치·판매 50% 환급)
  - 총 7종 시대별 고유 필살기(운석 낙하, 신의 번개, 불화살 비, 함포 일제사격, 폭격기 융단폭격, 전술 미사일 공습, 궤도 레이저 포격)
  - 7시대 4단 다층 패럴랙스 배경 및 기지 외형 독립 진화
- **Web Audio API 사운드 합성**: 외부 오디오 파일 없이 타격음·발사음·폭발·진화·필살기 음향 실시간 합성(음소거 토글 포함)
- **아이폰 사파리 / PWA 최적화**:
  - 가로 모드 전용 레이아웃 + Safe Area 대응 + 세로 진입 시 자동 일시정지 및 회전 안내
  - 전장 좌우 관성 드래그 + 상단 미니맵 터치 즉시 이동
  - 하단 엄지 조작 도크(유닛/포탑 탭, 5슬롯 생산 대기열 취소 환급, 진화/필살기 게이지)
  - 오프라인 캐시 Service Worker & `manifest.webmanifest`
- **전술형 적 AI**: 쉬움/보통/어려움 난이도, 로컬 최고 기록 저장(`localStorage`), 1x/2x 배속, 일시정지

## 실행 및 검증

```bash
npm install
npm run dev        # 로컬 개발 서버
npm run typecheck  # TypeScript 엄격 타입체크
npm test           # Vitest 단위 테스트
npm run build      # 프로덕션 번들 빌드
```

## GitHub Pages 배포

`.github/workflows/deploy.yml`이 포함되어 있어 `main` 브랜치에 푸시하면 자동으로 타입체크 → 테스트 → 빌드 → GitHub Pages 배포가 진행됩니다. (저장소 Settings → Pages → Source를 **GitHub Actions**로 설정)
